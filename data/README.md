# Data catalogue

This directory contains only compact inputs and result tables that support the portfolio figures. It does not redistribute raw single-cell or spatial transcriptomics objects.

## Dataset design reported in the project paper

- **Standard Visium:** healthy mouse liver, spatial series [GSE192741](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE192741), sample `GSM5764414`, from [Guilliams et al. (2022), *Cell*](https://doi.org/10.1016/j.cell.2021.12.018).
- **Visium HD:** a distinct healthy mouse liver dataset at 16 µm bin size, generated in-house and not publicly available at the time of the report.
- **Single-cell references:** the same study's single-cell/single-nucleus series is [GSE192740](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE192740). Subsequent split/HD analyses used the processed snRNA-seq (`nuclei`) reference with `annot_cd45` labels. This project used that prepared reference as an input; it did not generate or preprocess the underlying atlas data.

The group repository contains method outputs for standard-Visium slides `JB01`–`JB04`. The upstream benchmark evaluation script reads all four slides, summarizes each slide, and averages metrics across slides and the four selected snRNA-seq biological replicates. In contrast, the report's spatial full-versus-split experiment and its 1,293-spot agreement table are based on `JB01`. The compact matrices in this repository are therefore `JB01` outputs, not a pooled four-slide matrix.

## About `reference/digitized_snrna_composition_reference.csv`

This file is **not** the snRNA-seq expression reference used to run the methods. It preserves only the approximate nine-cell-type vector used by the group project's JSD plotting script, `provenance/group_project/plots/g_truth_plot.py`.

- The benchmark protocol calculated a composition for each of four snRNA-seq samples (`ABU11`, `ABU13`, `ABU17`, and `ABU20`) and averaged them into one representative distribution.
- The Spotless paper did not provide that distribution as a numeric table. According to the group report, the values were estimated from Spotless Figure 6—figure supplement 2 with WebPlotDigitizer and then hardcoded in the plotting script.
- `original_proportion` is the nine-cell-type vector as it appeared in that script. It sums to 0.871 because the `Others` category shown in the source bar plot was excluded.
- `normalized_within_nine_types` rescales those nine values to sum to one; this is the distribution used for the JSD calculation.
- The processed method input `liver_mouseStSt_nuclei_9celltypes_annot_cd45.rds` was not recovered locally and is not included.

Therefore, this table is an approximate, digitized composition reference—not a direct recalculation from raw snRNA-seq and not spatial-bin-level ground truth.
