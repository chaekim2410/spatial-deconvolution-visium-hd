# Analysis scripts

These are the active, reusable scripts behind the compact portfolio results. They were created during portfolio curation from the group report, retained result matrices, and exploratory notebooks; they were **not copied unchanged from the original group GitHub repository**.

- `compare_full_vs_split.py` reassembles split results by spot ID and calculates dominant-cell-type agreement, mean absolute error, and correlation against a full-tissue run.
- `make_figures.py` creates README Figures 00–06 from the compact inputs and summaries in `data/` and `results/`.
- `summarize_visium_hd.py` converts local partition-level HD outputs into shareable method/partition summaries; it does not write spot-level data.
- `visium_hd_qc.py` calculates basic HD gene and UMI-count QC from an AnnData input.

`make_figures.py` can be run with `MPLBACKEND=Agg python analysis/make_figures.py` after installing `requirements.txt`. Scripts needing an AnnData object or local HD outputs are templates for authorized inputs and are not runnable from this repository alone.

All PNG files currently published in `results/figures/` are generated by `make_figures.py`. See `results/README.md` for the exact input and provenance of every figure and result table.
