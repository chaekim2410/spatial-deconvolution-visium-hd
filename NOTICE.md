# Notice and provenance

This repository is a focused derivative of two earlier bodies of work:

1. **Spotless**, a reproducible pipeline for benchmarking spatial deconvolution tools, by Sang-aram et al.
2. **Scalable deconvolution in high-resolution spatial transcriptomics: a benchmark on Visium HD data**, a Ghent University group project by Sarah Verschuere, Chaeyoung Kim, Hyojun Bae, and Dries Huybens.

The portfolio branch starts from Sang-aram et al.'s Spotless repository. Selected group-project files were recovered from the local course repository and are retained with their group authorship; this is not presented as a fork of an individual group member's GitHub repository.

Code adapted from the Spotless repository retains its original MIT license and contributor history. Standard Visium result matrices are included only when they are small and directly support the reported comparison. Visium HD raw data and spot-level outputs are excluded because the project materials do not identify a public download source; only aggregate summaries and non-reconstructive figures are retained.
