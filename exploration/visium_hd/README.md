# Visium HD notebooks

- `Creation_sdata_object_Visium_HD.ipynb`: creates the HD spatial object used in the project.
- `check_sparsity.ipynb`: the original HD QC and exploratory analysis: gene/UMI distributions, method-specific usable spots, spatial checks, and partition-level proportion comparisons.

`check_sparsity.ipynb` documents the original HD quality checks, method-specific spot usage, partition-level distributions, and dominant-cell-type Sankey analysis used in the group report. Its outputs are cleared and its original local paths require authorized HD inputs, so it is historical exploratory code rather than a one-command public workflow. The final multi-panel report assembly code was not recovered and is not claimed as reproducible here.
