# Standard-Visium notebooks

- `Creation_sdata_object_Visium.ipynb`: loads the standard-Visium data and builds a spatial object for exploration.
- `Visium_data_exploration.ipynb`: exploratory QC, preprocessing, and cell-type inspection.
- `Visualisations_visium.ipynb`: visualises deconvolution proportions and comparisons on the tissue.

These notebooks document the original exploratory work. The compact comparison used in the README is regenerated by `analysis/make_figures.py`.
