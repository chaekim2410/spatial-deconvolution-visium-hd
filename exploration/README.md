# Exploratory notebooks

The notebooks preserve the practical exploration that informed the final workflow. Outputs were cleared so the repository stays compact, and several notebooks contain historical local paths; use `analysis/` for the portable, active scripts.

- `visium/` contains standard-Visium object creation, QC exploration, and result visualisation.
- `visium_hd/` contains HD object creation, QC/sparsity exploration, and result-table merging.
