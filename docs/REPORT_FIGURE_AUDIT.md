# Group-report figure audit

The group report contains twelve figures, but the exact final plotting/assembly code was not recovered for every panel. This focused portfolio therefore does not claim that every report figure is reproducible from the public repository.

| Report figure | Subject | Recovered source status |
|---|---|---|
| 1 | General Visium/Visium HD illustration | externally sourced illustration; not project-generated code |
| 2 | Four reference conditions across three methods | underlying all-slide proportion code is in upstream `scripts/liver_analysis/3a_evaluate_liver_visium.R` sections 1–2; it reads `JB01`–`JB04`; exact report export/assembly not verified |
| 3 | JSD to benchmark result across reference conditions | all-slide JSD calculation is in the same upstream R script sections 4–5; exact report heatmap/export not verified |
| 4 | Four spatial partitions | splitting code and `exploration/visium/Creation_sdata_object_Visium.ipynb` recovered; portfolio equivalent generated as Figure 01 |
| 5 | Full-versus-split spot proportions | `JB01` merge/comparison code retained in the Visium creation and visualisation notebooks; portfolio equivalent generated as Figure 02 |
| 6 | Spatial dominant-type matches/mismatches | `JB01` match columns and plotting code retained in the Visium creation and visualisation notebooks; portfolio equivalent generated as Figure 03 |
| 7 | cell2location run-to-run mismatch map | `JB01` Part 0 run-to-run comparison retained in the Visium notebooks; exact report assembly not verified |
| 8 | Visium HD gene/UMI QC | calculation and plotting logic retained in `exploration/visium_hd/check_sparsity.ipynb`; exact report assembly not verified |
| 9 | Cross-method dominant-type Sankey plots | Sankey code retained in `exploration/visium_hd/check_sparsity.ipynb`; exact report assembly not verified |
| 10 | HD proportion distributions by method/partition | boxplot code retained in the exploratory notebook; exact report assembly not verified |
| 11 | Digitized snRNA-seq composition | obtained with WebPlotDigitizer, not generated by Python |
| 12 | Visium versus Visium HD JSD | historical plotting code retained in `provenance/group_project/plots/true_cell_prop.py`; portfolio equivalent generated as Figure 05 |

Only figures generated by the active portfolio script are placed in `results/figures/`. Historical code is kept separately under `exploration/` or `provenance/` so it is not confused with the active reproducible interface.

The report figures were not produced by one Python script. Their sources are split across an upstream R benchmark-evaluation script, project Jupyter notebooks, historical Python plotting scripts, and WebPlotDigitizer. “Code retained” therefore means that the underlying calculation/plotting logic was recovered; it does not imply that every final multi-panel report image can be rebuilt byte-for-byte from the public repository.
