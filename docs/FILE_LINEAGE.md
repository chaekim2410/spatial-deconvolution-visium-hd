# File lineage

This portfolio combines recovered group-project artifacts with newly curated, reusable analysis code. The categories below prevent the curated code from being mistaken for files copied from the original group repository.

| Location | Lineage |
|---|---|
| `analysis/*.py` | newly written during portfolio curation from the report, retained outputs, and exploratory notebooks |
| `exploration/` | original local group-project notebooks, with outputs cleared and explanatory READMEs added |
| `execution/split/` | recovered group-project splitting function and its test notebook |
| `execution/run_methods/run_split_deconvolution.pbs` | portable cleanup of the group's PBS submission pattern; private HPC paths removed |
| `execution/merge/` | recovered group-project partition-merging notebook, renamed for clarity |
| `data/proportions/` | selected group-project deconvolution result matrices, renamed into a consistent portfolio layout |
| `data/assignments/` and `data/coordinates/` | compact recovered inputs supporting the standard-Visium comparison |
| `results/derived_summaries/` | tables recomputed during portfolio curation from retained outputs or local group-project HD outputs |
| `results/figures/` | figures generated by the curated `analysis/make_figures.py` script |
| `provenance/group_project/` | historical plotting scripts copied from the recovered group-project repository for traceability; not the active interface |

Files from the upstream Spotless benchmark are linked and attributed rather than presented as original portfolio code.

## Active analysis files shown on GitHub

The four files in `analysis/` are portfolio-curation code, not unchanged files copied from the earlier group repository:

| File | How it was produced |
|---|---|
| `compare_full_vs_split.py` | newly organized from the full/split comparison logic and retained matrices |
| `make_figures.py` | newly written as the single reproducible entry point for the published portfolio figures |
| `summarize_visium_hd.py` | newly written to convert authorized local HD outputs into non-reconstructive summaries |
| `visium_hd_qc.py` | newly written from the QC operations retained in the HD exploration notebook |

The historical material that supports those scripts remains separately identifiable under `exploration/`, `execution/`, and `provenance/`.

The recovered HD PBS submission and a record of the group-specific Nextflow HPC-profile changes are also retained under `provenance/group_project/execution/`. The active PBS file is a portable cleanup with private paths replaced by required environment variables.
