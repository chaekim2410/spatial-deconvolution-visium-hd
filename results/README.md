# Results provenance

This directory separates paper-reported values from summaries regenerated from retained outputs.

## Reported tables

- `reported_summary.csv`: standard Visium full-versus-split dominant-label agreement reported in the project paper.
- `visium_vs_hd_digitized_reference_jsd.csv`: reported Jensen-Shannon divergence values comparing Visium and Visium HD outputs with the digitized snRNA-seq composition reference.
- `visium_hd_qc_summary.csv`: reported Visium HD quality-control counts and method-specific spot retention.

## Derived summaries

- `derived_summaries/rctd_all_parts_metrics.csv`: recomputed from the retained full and split standard Visium RCTD matrices.
- `derived_summaries/cell2location_part0_metrics.csv`: recomputed from the retained full and Part 0 standard Visium cell2location matrices.
- `derived_summaries/visium_hd_part_composition.csv`: aggregate cell-type composition by method and spatial partition.
- `derived_summaries/visium_hd_spot_usage.csv`: aggregate accepted and rejected spot counts by method and partition.

These are small tables calculated from group-project outputs; they are not raw data. The underlying spot-level HD matrices are not included in this repository.

Every PNG currently in `figures/` is generated by `analysis/make_figures.py`:

| `04_reported_dominant_agreement.png` | `reported_summary.csv` | figure reproducible; underlying NNLS value is transcribed from the report |
| `05_visium_vs_hd_digitized_reference_jsd.png` | `visium_vs_hd_digitized_reference_jsd.csv` | figure reproducible; numeric JSD values are transcribed from the report |

Historical report figures whose exact final assembly code could not be verified are not published in this result directory. Their underlying exploratory logic remains in `exploration/visium_hd/check_sparsity.ipynb` and `provenance/group_project/`.
